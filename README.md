# 班级信息静态网页系统

一个面向**班级负责人**的轻量班级信息页面集合，用原生 HTML + CSS 写成。
不需要服务器、不需要数据库、不需要联网，用浏览器打开就能用。

---

## 1. 项目解决什么问题

班级负责人在日常事务里有两件高频小事特别烦：

- **查名单**：要找人、要报人数时，得翻 Excel、翻聊天记录；
- **收信息**：让同学报姓名学号，得在群里刷屏统计。

本项目把这两件事做成一个**打开即用的静态网页**：

| 原来的做法 | 现在的做法 |
| --- | --- |
| 翻 Excel / 群聊记录找学号 | 双击打开名单页，一屏看全 |
| 群里挨个统计姓名学号 | 打开录入页，填完提交 |
| 要装软件、要联网、要登录 | 零安装、零依赖、离线可用 |

**面向的场景很明确**：使用者是班级负责人（非程序员），电脑上不想装任何东西，拷个文件夹就能用。

## 2. 主要功能

### 页面一：首页 `index.html`
- 项目介绍、班级简介（安徽师范大学 计算机科学与技术 2026 级）
- 卡片式导航入口，点击整块卡片即可跳转到其他页面

### 页面二：班级名单 `roster.html`
- 使用标准 `table / thead / th / tbody / tr / td` 结构展示全班同学
- 四列：**序号、姓名、学号、联系方式**
- 鼠标指向某一行时整行高亮，方便横向对齐读数据
- 表格下方显示统计信息：`共 12 名同学 · 数据更新于 2026-10-08`
- 窄屏（手机）下表格可横向滚动，不挤压内容

### 页面三：信息录入 `form.html`
- 两个输入项：**姓名**（必填）、**学号**（必填）
- 学号带格式校验：必须是 **10 位数字**（如 `2026110113`）
- 点击「提 交」后：页面顶部弹出绿色提示条反馈结果，并自动清空输入框，方便连续录入下一位同学

### 三个页面通用的功能
- **顶部导航栏**：三个页面互相跳转，「当前所在页」自动高亮
- **吸顶导航**：页面滚动时导航栏固定在顶部
- **响应式布局**：电脑、手机都能正常显示
- **零外部依赖**：无框架、无 CDN、无外部字体，断网也完全正常

## 3. 安装方法

**本系统不需要安装。** 没有 `npm install`，没有 `pip install`，也不需要 Node.js 或 Python。

你只需要拿到下面 4 个文件（它们**必须在同一个文件夹里**）：

```
班级信息台/
├── index.html      首页
├── roster.html     班级名单
├── form.html       信息录入
├── style.css       公共样式（三个页面共用）
├── README.md       本说明文件
└── LICENSE         MIT 开源许可证
```

获取方式二选一：

1. **拷贝文件夹**：把整个文件夹复制到桌面、U 盘或任意位置；
2. **Git 克隆**（如果已发布到仓库）：
   ```bash
   git clone <仓库地址>
   ```

> 注意：`style.css` 是三个页面的公共样式表，**不要把它和 HTML 文件分开放**，否则页面会变成没有样式的白板。

### 可选：启动本地预览服务

直接双击打开已经完全够用。如果你想用 `localhost` 访问（比如为了后续接后端接口），可以在该文件夹下执行：

```bash
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。这一步是**可选的**，跳过不影响使用。

## 4. 使用方法

### 4.1 打开系统

双击 `index.html`，用 Chrome / Edge / Firefox 等现代浏览器打开即可。

### 4.2 查看班级名单

1. 在顶部导航点击「**班级名单**」，或点击首页的「📋 班级名单 →」卡片；
2. 页面以表格展示全部同学信息，鼠标放在某一行可高亮该行。

### 4.3 录入新同学信息

1. 在顶部导航点击「**信息录入**」；
2. 填写「姓名」和「学号」，两项都是必填；
3. 点击「**提 交**」按钮；
4. 提交成功后，页面顶部出现绿色提示条，输入框自动清空。

### 4.4 修改班级名单数据（负责人常用）

用记事本 / VS Code 打开 `roster.html`，找到 `<tbody>` 里的 `<tr>` 行，直接改 `<td>` 里的内容即可：

```html
<tr>
  <td>1</td>                 <!-- 序号 -->
  <td>张三</td>             <!-- 姓名 -->
  <td>2026110101</td>        <!-- 学号 -->
  <td>138-0000-0001</td>     <!-- 联系方式 -->
</tr>
```

- **改人**：直接修改对应单元格的文字；
- **加人**：复制一整段 `<tr> ... </tr>`，粘贴到 `</tbody>` 前面再改内容；
- **删人**：整段 `<tr> ... </tr>` 删掉。

改完记得同步更新表格下方的统计文字（`共 N 名同学`）。

### 4.5 换一套配色

打开 `style.css`，改最上面的 `:root` 变量即可，全站颜色会一起变：

```css
:root {
  --primary: #2f6fed;        /* 主色：链接、按钮、高亮 */
  --primary-dark: #1f56c4;   /* 主色加深：鼠标悬停时 */
  --bg: #f5f7fb;             /* 页面背景 */
}
```

## 5. 输入输出示例

### 示例一：正常提交信息

**输入**（在 `form.html` 中填写）：

| 字段 | 填写内容 |
| --- | --- |
| 姓名 | `张三` |
| 学号 | `2026110113` |

**输出**：点击「提 交」后，页面顶部出现绿色提示条：

```
✅ 已提交：张三（学号 2026110113）— 静态页面演示，数据未被真实保存
```

同时两个输入框被清空，光标回到可继续输入的状态。

### 示例二：学号格式不符（校验拦截）

**输入**：

| 字段 | 填写内容 |
| --- | --- |
| 姓名 | `张三` |
| 学号 | `123` |

**输出**：表单**不会提交**，浏览器在学号输入框下方弹出原生提示：

```
学号应为 10 位数字
```

（该提示文案来自 `form.html` 中学号输入框的 `title` 属性，由 `pattern="\d{10}"` 规则触发。）

### 示例三：必填项留空

**输入**：姓名留空，直接点「提 交」。

**输出**：表单**不会提交**，浏览器提示 `请填写此字段`，光标自动定位到姓名输入框。

### 示例四：名单页的展示结果

**输出**（`roster.html` 表格的前两行渲染效果）：

| 序号 | 姓名 | 学号 | 联系方式 |
| --- | --- | --- | --- |
| 1 | 张三 | 2026110101 | 138-0000-0001 |
| 2 | 王雨桐 | 2026110102 | 138-0000-0002 |

## 已知限制

这几条是实现现状，不是 bug，写清楚避免误会：

1. **数据不会真正保存**。本项目是纯静态页面，没有后端服务器，表单提交只在浏览器本地做校验和提示，刷新页面后录入内容即消失。
   如需真正收集数据，可把 `form.html` 中 `<form>` 的 `action="#"` 改成后端接口地址，或先用在线表单工具过渡。
2. **名单数据是示例内容**。`roster.html` 中的姓名与联系方式均为占位数据（电话形如 `138-0000-000X`），使用前请替换为真实名单。
3. **不支持搜索和排序**。名单页目前是纯静态表格，同学数量较多时建议配合浏览器 `Ctrl + F` 查找。

## 技术说明

- **技术栈**：原生 HTML5 + CSS3（一期仅 `form.html` 使用约 20 行原生 JS 做提交反馈）
- **零框架**：未使用 Vue / React / Bootstrap / jQuery 等任何库
- **零依赖**：无 CDN、无外部字体、无构建步骤
- **代码注释**：所有 HTML / CSS 文件均含中文注释，逐处说明标签与属性的作用，适合作为新手教学参考
