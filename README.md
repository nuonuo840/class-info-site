# 班级信息静态网页系统

一个面向**班级负责人**的轻量班级信息页面集合，用原生 HTML + CSS + JavaScript 写成。
不需要服务器、不需要数据库、不需要联网，用浏览器打开就能用。

**在线体验**：<https://nuonuo840.github.io/class-info-site/>

---

## 1. 项目解决什么问题

班级负责人在日常事务里有两件高频小事特别烦：

- **查名单**：要找人、要报人数时，得翻 Excel、翻聊天记录；
- **收信息**：让同学报姓名学号，得在群里刷屏统计。

本项目把这两件事做成一个**打开即用的静态网页**：

| 原来的做法 | 现在的做法 |
| --- | --- |
| 翻 Excel / 群聊记录找学号 | 打开名单页，一屏看全，还能搜索 |
| 群里挨个统计姓名学号 | 打开录入页，填完提交，名单页立刻出现 |
| 要装软件、要联网、要登录 | 零安装、零依赖、离线可用 |

**面向的场景很明确**：使用者是班级负责人（非程序员），电脑上不想装任何东西，拷个文件夹就能用。

## 2. 主要功能

### 页面一：首页 `index.html`
- 项目介绍、班级简介（某高校 计算机类专业 2026 级）
- 班级简介里的「现有同学 N 人」会**自动读取实际人数**，不会和名单对不上
- 卡片式导航入口，点击整块卡片即可跳转到其他页面

### 页面二：班级名单 `roster.html`
- 使用标准 `table / caption / thead / th / tbody / tr / td` 结构展示全班同学
- 四列：**序号、姓名、学号、联系方式**
- **关键词搜索**：输入姓名或学号即时筛选，不需要按回车
- 序号取同学在完整名单中的位置，**搜索结果里序号依然稳定**，不会重新从 1 开始
- 搜索无结果时给出提示文字，不会出现空白表格
- 鼠标指向某一行时整行高亮，方便横向对齐读数据
- 窄屏（手机）下表格可横向滚动，不挤压内容
- 表格下方显示统计：`共 N 名同学 · 数据保存在本机浏览器`

### 页面三：信息录入 `form.html`
- 两个输入项：**姓名**（必填）、**学号**（必填）
- 学号带格式校验：必须是 **10 位数字**（如 `2026110113`）
- **学号查重**：已存在的学号会被拒绝，不会重复录入
- 点击「提 交」后：页面顶部弹出提示条反馈结果，并自动清空输入框，方便连续录入下一位同学
- **提交的数据会真正保存下来**（存在浏览器本地），刷新不丢，名单页立刻能看到

### 三个页面通用的功能
- **顶部导航栏**：三个页面互相跳转，「当前所在页」自动高亮
- **吸顶导航**：页面滚动时导航栏固定在顶部
- **响应式布局**：电脑、手机都能正常显示
- **打印样式**：打印名单时自动隐藏导航、按钮、搜索框，表格转为黑白线条，可直接打印或另存为 PDF
- **无障碍**：表格带 `caption` 与 `scope="col"`，提交结果用 `aria-live` 播报，键盘也能操作
- **零外部依赖**：无框架、无 CDN、无外部字体，断网也完全正常

## 3. 安装方法

**本系统不需要安装。** 没有 `npm install`，没有 `pip install`，也不需要 Node.js 或 Python。

你只需要拿到下面这批文件（**6 个代码文件必须在同一个文件夹里**）：

```
班级信息台/
├── index.html      首页
├── roster.html     班级名单
├── form.html       信息录入
├── style.css       公共样式（三个页面共用）
├── app.js          数据层（名单的读取与保存，名单页与录入页共用）
├── favicon.svg     浏览器标签页图标
├── README.md       本说明文件
└── LICENSE         MIT 开源许可证
```

获取方式三选一：

1. **直接在线用**：打开 <https://nuonuo840.github.io/class-info-site/> ，不下载也能用；
2. **拷到本地**：从 ZIP 解压或拷贝整个文件夹到桌面、U 盘即可；
3. **Git 克隆**：
   ```bash
   git clone https://github.com/nuonuo840/class-info-site.git
   ```

> 注意：`style.css`、`app.js`、`favicon.svg` 都不要和 HTML 文件分开放，否则页面会变成没有样式的白板，或者名单加载不出来。

### 可选：启动本地预览服务

直接双击打开已经完全够用。如果想用 `localhost` 访问，可以在该文件夹下执行：

```bash
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。这一步是**可选的**，跳过不影响使用。

## 4. 使用方法

### 4.1 打开系统

双击 `index.html`，用 Chrome / Edge / Firefox 等现代浏览器打开即可。

### 4.2 查看与搜索班级名单

1. 在顶部导航点击「**班级名单**」，或点击首页的「📋 班级名单 →」卡片；
2. 页面以表格展示全部同学信息，鼠标放在某一行可高亮该行；
3. 在表格上方的搜索框里输入**姓名或学号**的任意片段，表格会即时筛选；
4. 清空搜索框即恢复完整名单。

### 4.3 录入新同学信息

1. 在顶部导航点击「**信息录入**」；
2. 填写「姓名」和「学号」，两项都是必填；
3. 点击「**提 交**」按钮；
4. 提交成功后：
   - 页面顶部出现绿色提示条，显示已录入的姓名、学号和当前总人数；
   - 输入框自动清空；
   - 切到「班级名单」页，新同学已经在表格里了。

如果学号已经存在，会显示红色提示条并拒绝录入。

### 4.4 修改班级名单数据（负责人常用）

名单数据集中在 **`app.js` 顶部的 `DEFAULT_STUDENTS` 数组**里，改这一处即可：

```js
var DEFAULT_STUDENTS = [
  { name: '张三',   sid: '2026110101', contact: '138-0000-0001' },
  { name: '王雨桐', sid: '2026110102', contact: '138-0000-0002' },
  // 加人：照格式加一行即可，序号和人数会自动算
];
```

- **改人**：修改对应那一行；
- **加人**：复制一行粘贴，改成新同学的信息；
- **删人**：整行删掉。

顺序就是名单顺序，**不需要手动写序号，也不需要手动改人数**。

> **一个重要提醒**：如果你之前已经在页面里录入过同学，浏览器里会存有一份本地数据，
> 它的优先级高于 `DEFAULT_STUDENTS`，所以改数组后页面不会立刻变化。
> 这时在浏览器控制台执行一句 `ClassData.reset()` 再刷新，即可清空本地数据、回到你改好的默认名单。

### 4.5 换一套配色

打开 `style.css`，改最上面的 `:root` 变量即可。**全站所有颜色都取自这组变量**，改完整个站点会一起变，不会出现"按钮变了但表头还是蓝的"这种情况：

```css
:root {
  --primary: #2f6fed;        /* 主色：链接、按钮、当前页高亮 */
  --primary-dark: #1f56c4;   /* 主色加深：按钮 hover */
  --primary-soft: #eef3ff;   /* 主色浅底：导航 hover、表头背景 */
  --primary-faint: #f8faff;  /* 主色极浅底：表格行 hover */
  --primary-glow: rgba(47, 111, 237, .12);   /* 主色光晕：聚焦光圈、阴影 */
}
```

### 4.6 打印名单 / 导出 PDF

1. 打开「班级名单」页，按 `Ctrl + P`（Mac 为 `Cmd + P`）；
2. 导航栏、页脚、搜索框、按钮会**自动隐藏**，表格转为适合黑白打印的线条样式；
3. 在打印对话框里选择打印机，或把目标改成「另存为 PDF」即可导出。

### 4.7 清空本地数据

在浏览器控制台执行 `ClassData.reset()`，然后刷新页面，即可清空已录入的数据、恢复成 `app.js` 里的默认名单。

## 5. 输入输出示例

### 示例一：正常提交信息

**输入**（在 `form.html` 中填写）：

| 字段 | 填写内容 |
| --- | --- |
| 姓名 | `张三` |
| 学号 | `2026110113` |

**输出**：点击「提 交」后，页面顶部出现绿色提示条：

```
已录入：张三（学号 2026110113），当前共 13 名同学。数据保存在本机浏览器。
```

同时两个输入框被清空，光标回到可继续输入的状态。切换到「班级名单」页，表格末尾会多出一行：

| 序号 | 姓名 | 学号 | 联系方式 |
| --- | --- | --- | --- |
| 13 | 张三 | 2026110113 | — |

> 联系方式显示为 `—`，因为录入表单目前只收集姓名和学号。这个数字可以改成别的，或把联系方式补进 `app.js`。

### 示例二：学号格式不符（校验拦截）

**输入**：

| 字段 | 填写内容 |
| --- | --- |
| 姓名 | `张三` |
| 学号 | `123` |

**输出**：表单**不会提交**，浏览器在学号输入框下方弹出原生提示：

```
学号应为 10 位数字
```

（该提示文案来自 `form.html` 中学号输入框的 `title` 属性，由 `pattern="\d{10}"` 规则触发。）

### 示例三：学号重复

**输入**：姓名 `李四`，学号 `2026110101`（名单里已存在）。

**输出**：表单**不会**写入新数据，页面顶部出现红色提示条：

```
学号 2026110101 已存在，未重复录入。
```

### 示例四：必填项留空

**输入**：姓名留空，直接点「提 交」。

**输出**：表单**不会提交**，浏览器提示 `请填写此字段`，光标自动定位到姓名输入框。

### 示例五：搜索筛选

**输入**：在名单页搜索框里输入 `20261101`。

**输出**：表格只保留学号包含该片段的同学，底部统计文字变为：

```
筛选出 12 名同学（共 12 名）
```

若输入一个不存在的关键词（如 `zzz`），表格会显示：

```
没有匹配的同学，换个关键词试试。
```

### 示例六：名单页的展示结果

**输出**（`roster.html` 表格的前两行渲染效果）：

| 序号 | 姓名 | 学号 | 联系方式 |
| --- | --- | --- | --- |
| 1 | 张三 | 2026110101 | 138-0000-0001 |
| 2 | 王雨桐 | 2026110102 | 138-0000-0002 |

## 已知限制

这几条是实现现状，不是 bug，写清楚避免误会：

1. **数据保存在浏览器本地，不是保存在服务器**。录入的信息存在当前电脑、当前浏览器的 `localStorage` 里，刷新和关机都不会丢，但**换一台电脑、换一个浏览器、或清空浏览器数据就会回到默认名单**。如果需要多人各自提交、汇总到一处，必须接后端接口或改用在线表单工具。
2. **名单默认数据是示例内容**。`app.js` 里的姓名与联系方式均为占位数据（电话形如 `138-0000-000X`），使用前请替换为真实名单。
3. **不支持排序和导出**。名单目前按录入顺序展示，可以搜索但不能按学号排序，也没有导出 CSV/Excel 的功能。
4. **名单页只在打开时读取一次数据**。如果你在另一个标签页新增了同学，刷新名单页即可看到最新数据。

## 技术说明

- **技术栈**：原生 HTML5 + CSS3 + ES5 JavaScript（无 ES6 语法，兼容性更好）
- **结构**：
  - `style.css` —— 全站样式，所有颜色收敛在 `:root` 变量里
  - `app.js` —— 数据层，负责名单的读取、保存、查重与匹配，被名单页和录入页共用
  - 三个 HTML 页面 —— 只负责结构与各自的交互逻辑
- **零框架**：未使用 Vue / React / Bootstrap / jQuery 等任何库
- **零依赖**：无 CDN、无外部字体、无构建步骤，拷贝文件夹即可运行
- **代码注释**：所有 HTML / CSS / JS 文件均含中文注释，逐处说明作用，适合作为新手教学参考
