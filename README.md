# 班级信息平台

一个面向**班级负责人**的轻量班级信息平台，用原生 HTML + CSS + JavaScript 写成。
不需要服务器、不需要数据库、不需要联网，用浏览器打开就能用。

平台以**学校**为单位组织，首页按**专业 → 班级**逐级选择，进入后查看该班的同学名单。

**在线体验**：<https://nuonuo840.github.io/class-info-site/>

---

## 1. 项目解决什么问题

一个学院、一个专业往往有多个班级，班级负责人在日常事务里有两件高频小事特别烦：

- **查名单**：要找人、要报人数时，得翻 Excel、翻聊天记录；
- **收信息**：让同学报姓名、学号、手机号，得在群里刷屏统计。

而且这件事要按班级分开做 —— 1 班的名单不能混进 2 班的人，各班数据不能互相干扰。

本项目把这些事做成一个**打开即用的静态网页**：

| 原来的做法 | 现在的做法 |
| --- | --- |
| 每个班一个 Excel，散落各处 | 一个平台装下所有班级，按专业班级进入 |
| 翻 Excel / 群聊记录找学号 | 打开班级名单页，一屏看全，还能搜索 |
| 群里挨个统计姓名学号手机号 | 打开录入页，填完提交，名单页立刻出现 |
| 要装软件、要联网、要登录 | 零安装、零依赖、离线可用 |

**面向的场景很明确**：使用者是班级负责人（非程序员），电脑上不想装任何东西，拷个文件夹就能用。

## 2. 主要功能

### 页面一：首页 `index.html`
- **选择班级**：专业下拉框 + 班级下拉框联动，选好后点「进入班级」直达该班名单，或点「直接录入」去该班录入页
- **班级概览**：每个班级一张卡片，显示班级全名与当前人数，点卡片直接进班
- **新建班级**：预置班级之外，可自己填写「专业 / 年级 / 班级名」创建新班级（保存在本机浏览器）
- **删除班级**：卡片右侧的「删除」可以删掉任意班级（**会连这个班的整份名单一起删**，所以先弹窗告知有几个人）；预置班级删掉后还能一键恢复
- **学校设置**：直接改全站显示的学校名，保存后顶部、页脚、标题里的校名立刻跟着变（改完存在本机浏览器）
- **数据管理**：两个按钮 —— 「清空本机全部数据」把全部名单、自建班级和学校设置恢复到初始状态；「恢复预置班级」把之前删掉的预置班级找回来（都会先弹窗确认）
- 项目介绍与全校统计（共几个班、共多少名同学），人数**自动读取实际数据**，不会对不上

### 页面二：班级名单 `roster.html?c=班级编号`
- **一个页面服务所有班级**：通过网址参数 `c` 指定看哪个班，例如 `roster.html?c=cs-2026-1`
- **失效链接不是死路**：网址没带班级编号（点了旧书签）、或编号不存在（链接被截断、班级被移除）时，页面会**就地给出「专业 → 班级」选择器**，选完点「查看名单」直接进入，不用回首页重来；编号不存在时还会用橙色提示条说明原因
- 页面顶部显示**班级全名**（如「计算机科学与技术 2026 级 1 班」）与**位置提示**（首页 › 专业 › 班级）
- 使用标准 `table / caption / thead / th / tbody / tr / td` 结构展示全班同学
- 七列：**勾选、序号、姓名、性别、学号、联系方式、操作**（班级自己加了字段的话，「联系方式」和「操作」之间还会多出对应的列）
- **在名单里直接修改同学信息**：点某行右侧的「编辑」，这一行的姓名、性别、学号、联系方式（以及自定义字段）就地变成输入框 / 下拉框，改完点「保存」即时生效；按 `Enter` 保存、按 `Esc` 取消
- **批量修改不再一行行点保存**：凡是有一行在编辑，表格上方就会出现一条编辑工具条 —— 点「**保存全部**」把所有改过的行一次存掉，或者按 **`Ctrl + Enter`**（macOS 上是 `⌘ + Enter`）。旁边的「全部取消」放弃这一批改动
- **留空的一栏照样能存**：只有**姓名和学号**是必填的 —— 联系方式、性别、自定义字段留空都能保存（以前联系方式留空会被拦下，0.4.1 已改）
- **给班级加自己的字段**：工具条上的「**字段**」可以给这个班加几栏本班特有的信息（宿舍号、QQ、家长电话…），加完立刻出现在表格里，录入页也能填、导出也带上（详见 4.19）
- **删除同学**：点某行的「删除」，弹窗确认后把这位同学从本班移除（删完还能用顶部的「撤销」退回）
- **调整名单顺序**：每行操作列里还有「**上移**」「**下移**」，把这位同学在名单里挪一位，序号自动重排（正在搜索筛选时不提供这两个按钮，免得看不到全貌）
- **按学号排序**：工具条上的「按学号排序」一键把整份名单按学号从小到大重排，序号跟着变；排错了可以用「撤销」退回原来的顺序
- **批量导入**：工具条上的「导入」展开一个面板，可以从 **CSV 文件**、或**直接从 Excel 复制粘贴**的内容批量导入同学 —— 先「识别」出一张预览表，看清会增加几位、哪几位会覆盖或跳过，再点确认（详见 4.12）
- **批量操作**：勾选多位同学后，表格上方会出现操作条，支持三种批量动作 ——
  - **移动到别的班级**：选好目标「专业 → 班级」，一键把这几位同学整班转过去
  - **批量修改信息**：让这几行**同时变成输入框**，改完可以各自点「保存」，也可以用上方的「保存全部」一次存完
  - **删除选中**：一次删掉勾中的多位同学（同样有确认）
- **撤销上一步**：删除、移动、修改信息、调整顺序、按学号排序、批量导入之后，页面上会浮出一条橙色的「上一步：……　[撤销]」，点「撤销」退回一步（**只在本次打开期间有效**，最多记 20 步，刷新页面就清空）
- **导出 CSV**：工具条上的「导出 CSV」把当前显示的名单（含性别列与自定义字段）存成表格文件，双击就能用 **Excel / WPS 打开**（带 BOM，中文不会乱码）；改完之后可以再用「导入」导回来
- **跨标签页自动同步**：在另一个标签页里加了同学，本页会自动重新加载；如果你正在编辑，就不打断你的输入，只提示一句，你可以手动点工具条上的「重新加载」
- 修改时带校验：学号必须符合**当前设置的学号规则**（见 4.15，默认 4~20 位数字），**学号改成本班其他人已占用的会被拒绝并给出提示**；联系方式不限格式（手机号 / 座机 / 邮箱都行）
- **移动到别的班时若学号撞车**：目标班里已经有人用了相同学号的那几位会**留在原班不动**，其余照常搬过去，提示条会说明是哪几个学号冲突（不会覆盖目标班的原有同学）
- **关键词搜索**：输入姓名、**性别**、学号、联系方式或任一自定义字段的任意片段即时筛选（输入 `13800000001` 和 `138-0000-0001` 都能搜到；搜「男」「女」可以一次筛出全班男生 / 女生）
- 序号取同学在**完整名单**中的位置，搜索结果里序号依然稳定
- 表格下方显示统计：`本班共 N 名同学 · 数据保存在本机浏览器，可修改、删除、排序、导入导出，也可勾选后批量操作`
- **初始名单是空的**：预置班级只搭好「专业 → 班级」的架子，里面**不含任何示例同学**，是干干净净的白纸。名单为空时会提示「这个班还没有名单数据，请到「信息录入」页添加第一位同学。」
- 窄屏（手机）下表格可横向滚动

### 页面三：信息录入 `form.html?c=班级编号`
- **在页面上直接选班级**：顶部有「专业 → 班级」两个联动下拉框，选哪个班就往哪个班录；选完之后**地址栏会自动更新**，刷新或收藏都不丢
- 网址参数 `c` 只是**默认值**而不是硬性要求：`form.html?c=cs-2026-1` 会默认选中 1 班，之后仍可在下拉框里改成别的班
- **不带参数也能直接打开**：默认选中第一个班级，并用一条蓝色说明条告知你；如果带的是不存在的编号，会给出橙色警告并退回第一个班
- 页面顶部会实时显示「正在录入：某某班」，并同步更新位置提示（首页 › 专业 › 班级）与页面标题
- 四个固定输入项：**姓名**（必填）、**性别**（选填）、**学号**（必填）、**联系方式**（选填）
- **性别是选填的**：下拉框里只有「未填写 / 男 / 女」三个值，留空就是「未填写」，名单页会显示成「—」，之后随时能补上
- 学号格式校验：位数由 `app.js` 顶部的**学号规则**统一决定（默认 **4~20 位数字**，见 4.15），输入框旁边会写明当前要求 —— 换学校只要改那一处，三个页面一起跟着变
- **联系方式完全自由**（0.4.1 起）：手机号、座机、邮箱、QQ / 微信号都收，**留空也行**。
  写得像 11 位手机号（`13800000013` 或 `138-0000-0001`）时，数据层会规整成纯数字存起来，名单页显示成更好读的 `138-0000-0001`
- **本班自己加的字段**也会出现在这一页（比如「宿舍号」），同样是选填；换班级时这几栏会跟着换成那个班的字段
- **学号查重**：学号在本班已存在时弹窗确认，选「确定」就用这次填写的信息**覆盖**原记录，选「取消」则原样不动（覆盖时只会动这次填的那几项，不会把这位同学其它栏的内容抹掉）
- 提交后顶部弹出提示条反馈结果（说明录进了哪个班、本班现有多少人），并自动清空几个输入框，方便连续录入下一位同学
  - **班级选择不会被清空** —— 连续给同一个班录入时不用反复重选
- **提交的数据会真正保存下来**（存在浏览器本地），刷新不丢，名单页立刻能看到

### 三个页面通用的功能
- **导航栏**：三个页面互相跳转，且名单页与录入页的链接会**自动带上当前班级**，不会跳到别的班或空页面
- **吸顶导航**：页面滚动时导航栏固定在顶部
- **响应式布局**：电脑、手机都能正常显示
- **打印样式**：打印名单时自动隐藏导航、按钮、搜索框、批量操作条、撤销条、位置提示，表格转为黑白线条，可直接打印或另存为 PDF
- **无障碍**：表格带 `caption` 与 `scope="col"`，提交结果用 `aria-live` 播报，键盘也能操作
- **零外部依赖**：无框架、无 CDN、无外部字体，断网也完全正常

## 3. 安装方法

**本系统不需要安装。** 没有 `npm install`，没有 `pip install`，也不需要 Node.js 或 Python。

你只需要拿到下面这批文件（**6 个代码文件必须在同一个文件夹里**）：

```
班级信息平台/
├── index.html      首页（选择班级）
├── roster.html     班级名单
├── form.html       信息录入
├── style.css       公共样式（三个页面共用）
├── app.js          数据层（班级目录 + 各班名单，三个页面共用）
├── favicon.svg     浏览器标签页图标
├── README.md       本说明文件
├── CHANGELOG.md    更新日志（各版本改了什么）
└── LICENSE         MIT 开源许可证
```

获取方式三选一：

1. **直接在线用**：打开 <https://nuonuo840.github.io/class-info-site/> ，不下载也能用；
2. **拷到本地**：从 ZIP 解压或拷贝整个文件夹到桌面、U 盘即可；
3. **Git 克隆**：
   ```bash
   git clone https://github.com/nuonuo840/class-info-site.git
   ```

> 注意：`style.css`、`app.js`、`favicon.svg` 都不要和 HTML 文件分开放，否则页面会变成没有样式的白板，或者名单加载不出来。

### 可选：启动本地预览服务

直接双击打开已经完全够用。如果想用 `localhost` 访问，可以在该文件夹下执行：

```bash
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。这一步是**可选的**，跳过不影响使用。

## 4. 使用方法

### 4.1 打开系统

双击 `index.html`，用 Chrome / Edge / Firefox 等现代浏览器打开即可。

### 4.2 选择班级并进入

1. 首页「**选择班级**」卡片里，先在左边的下拉框选**专业**；
2. 右边的下拉框会**联动**列出该专业下的所有班级，选中你要的班；
3. 点「**进入班级**」跳到该班名单页，或点「**直接录入**」去该班录入页。

也可以直接在「**班级概览**」里点某个班的卡片，一步进入。

> 顶部导航栏里的「班级名单」「信息录入」也会跟着你选的班级走，随时点随时进。

### 4.3 新建一个班级

1. 首页下方「**新建班级**」卡片里，填写**专业**、**年级**（默认 2026）、**班级名**（如 `3 班`）；
   - 「专业」输入框会提示已有的专业名，可以直接选，也可以填一个全新的专业；
2. 点「**创建班级**」；
3. 创建成功后，这个班**立刻出现在下拉框和概览卡片里**，并自动选中，可以直接进入。

**几点说明：**

- 新建的班级**只保存在你这台电脑的浏览器里**，不会写进代码文件，也不会同步给别人；
- 同一专业、同一年级下不能创建同名的班级，会提示「这个班级已经存在了」；
- 如果想把它变成"所有人都能看到"的固定班级，需要把它的信息补进 `app.js` 的 `DEFAULT_CLASSES` 数组（见 4.15）。

### 4.4 查看与搜索班级名单

1. 首页选好班级后点「进入班级」，或者在概览里点班级卡片；
2. 页面以表格展示该班全部同学信息，鼠标放在某一行可高亮该行；
3. 在表格上方的搜索框里输入**姓名、学号或联系方式**的任意片段（本班自定义字段里的内容也能搜到），表格会即时筛选；
4. 清空搜索框即恢复完整名单。

### 4.5 录入新同学信息

1. 在首页选好班级后点「直接录入」，或在名单页点「✍️ 给这个班录入新同学」；
2. 页面顶部会显示「正在录入：某某班」，确认班级没选错；
   - **想换班不用回首页**：直接在页面上的「专业 / 班级」下拉框里改，改完全页面（标题、位置提示、导航链接、地址栏）会一起跟着变；
3. 填写「姓名」「性别」「学号」「联系方式」——**姓名、学号两项必填，性别和联系方式都选填**；
   - **性别**：下拉框选「男」或「女」，不选就是「未填写」（名单页里显示成「—」），之后随时能补；
   - **学号**：位数要求由后台的**学号规则**决定，输入框旁边的提示写的就是当前要求（默认 4~20 位数字，见 4.15 的「改学号规则」）；
   - **联系方式**：手机号、座机、邮箱、QQ / 微信号都行，**留空也可以**（0.4.1 起不再校验格式）；写成 11 位手机号时存进去会统一成纯数字；
   - 如果这个班自己加过字段（宿舍号、QQ…），它们也会出现在表单里，同样都是选填（见 4.19）；
4. 点击「**提 交**」按钮；
5. 提交成功后：
   - 页面顶部出现绿色提示条，显示录入到了哪个班、姓名、学号和本班总人数；
   - 几个输入框自动清空，**班级选择保留**，方便接着录下一位；
   - 切到「班级名单」页，新同学已经在表格里了。

> **要一次录几十位同学？** 不用一条条敲 —— 到「班级名单」页点工具条上的「**导入**」，
> 把 Excel 里整理好的一份名单整批导进来（见 4.12）。

> 也可以直接打开 `form.html`（不带班级参数）：页面不会拦你，会默认选中第一个班级，
> 并用一条蓝色说明条提示这件事，你在下拉框里改一下就行。

**如果学号在本班已经存在**（例如之前漏填了联系方式，想补上）：页面会弹出确认框显示该学号原有同学的姓名和联系方式，点「确定」就用这次填写的内容覆盖，点「取消」则完全不动。所以**补填信息的做法是：用同一个学号重新录入一次，确认覆盖即可**。

### 4.6 修改同学信息（在名单页直接改）

1. 打开某班的「**班级名单**」页；
2. 找到要修改的同学，点这一行最右侧的「**编辑**」；
3. 该行的姓名、**性别**、学号、联系方式（以及本班的自定义字段）会就地变成输入框（性别是下拉框），直接改写内容；
4. 点「**保存**」（或按 `Enter` 键）即生效，页面顶部出现绿色提示条确认；
   - 不想改了：点「**取消**」或按 `Esc` 键，数据完全不动。

**几点说明：**

- **留空的栏也能保存**。只有姓名和学号是必填的 —— 联系方式、性别、自定义字段留空都不拦人（0.4.1 起；以前联系方式为空会被判"格式不对"）。
- **性别可以在这里补填**。下拉框里选「男 / 女 / —」，选「—」就是"未填写"。批量修改时这几行会同时出现下拉框，可以一次给好几位同学补上性别。
- **学号也能改**。如果学号当初填错了，改完保存即可。但如果改成**本班其他同学已占用**的学号，会被拒绝并提示，原数据不变。
- **校验不通过时不会清空你的输入**。比如学号位数不对，页面会提示并让你接着改，不会把你刚敲进去的内容冲掉。
- **编辑期间搜索框会临时禁用**。这是为了避免筛选刷新把没保存的修改覆盖掉，保存或取消后自动恢复。
- **没保存就关页面会提醒**。处于编辑状态时直接关标签页或跳转，浏览器会弹确认框。
- **修改结果同样存在浏览器本地**，刷新页面依然生效。

### 4.7 删除某位同学

1. 打开某班的「**班级名单**」页；
2. 找到要删除的同学，点这一行最右侧的「**删除**」；
3. 浏览器弹出确认框，显示这位同学的姓名与学号；
4. 点「**确定**」即从本班移除，页面顶部出现提示条并更新人数；点「**取消**」则完全不动。

**几点说明：**

- 删除之后可以用顶部的「**撤销**」退回（见 4.10），所以那次确认弹窗可以放心点；不过撤销只是临时保险，页面一刷新就没了，弹窗仍然保留；
- 删除的是**本班**的这一条记录，**不会影响别的班级**里有相同学号的同学（各班数据本来就是各存各的）；
- 表格上方的搜索**不会**影响删除的正确性：搜索状态下删除的，仍然是这一行对应那位同学。

### 4.8 批量修改 / 批量移动 / 批量删除

名单最左侧一列是**勾选框**，表头的勾选框可以一键全选/全不选。

勾中任意一位同学后，表格上方会**自动浮出一条批量操作条**，左侧显示「已选 N 人」，右侧是三个动作按钮（外加一个「取消选择」）：

| 按钮 | 作用 |
| --- | --- |
| **批量修改信息** | 被勾中的这几行**同时变成输入框**，改完点上方编辑条上的「**保存全部**」一次存完（也可以按 `Ctrl + Enter`；想单独存某一行，仍可按 `Enter` 存那一行、`Esc` 取消那一行） |
| **移动到「班级」→ 移动过去** | 先在下拉框里选目标「专业 → 班级」，再点「**移动过去**」，把这几位同学整体转到那个班 |
| **删除选中** | 一次删掉勾中的多位同学（会先弹窗确认，并显示要删几个人） |
| **取消选择** | 清空勾选，操作条自动收起 |

进入批量修改后，表格上方会多出一条蓝色的编辑工具条：

| 元素 | 作用 |
| --- | --- |
| **正在修改 N 位同学** | 告诉你现在有几行还没保存 |
| **保存全部** | 把这几行一次全部存掉，整批只记成**一步撤销**（点一次「撤销」全部退回） |
| **全部取消** | 放弃这一批还没保存的改动 |
| `Ctrl + Enter` | 和「保存全部」等价，光标在哪个格子里都能按 |

**保存全部是"先全部校验、再统一写入"**：只要有一行没填好（比如姓名空了），整批都不写，光标跳到出问题的那一格，改好后再点一次即可 —— 不会出现"存了一半、剩下几行还停在编辑态"的情况。

**移动到别的班时如果学号撞车怎么办？**

- 目标班里**已经有人用了相同学号**的那几位同学，会**留在原班不动**，其余照常搬过去；
- 提示条会用橙色说明是哪几个学号冲突，例如「其中 1 位因学号冲突留在原班：2026110103」；
- **绝不会覆盖目标班里原有的同学**——这一点比"搬过去"更重要；
- 移动完成后，原班和目标班的人数都会跟着变，刷新也依然生效。

**几点说明：**

- 批量修改时，**每一行独立校验**：某一行填错了，只有那一行保存失败并提示，不影响已经保存好的其他行；
- 用「保存全部」时则是**整批校验**：有一行没填好就整批先不写（见上一节的说明）；
- 搜索筛选会清空当前勾选（避免"选中了却看不见"的误删）；
- 只剩一位同学时也可以走批量操作，但通常直接用行内的「编辑 / 删除」更顺手。

### 4.9 调整名单顺序

**办法一：一位一位挪**

名单页每一行的操作列里都有「**上移**」「**下移**」两个按钮，点一下就把这位同学在名单里挪一位，序号自动重排。

- 排在最上面的同学，「上移」按钮是灰的；排在最下面的，「下移」是灰的；
- **正在搜索筛选时不显示这两个按钮** —— 因为调的是完整名单里的位置，筛选状态下你看不到全貌，点了会一头雾水；
- 调整结果同样存在浏览器本地，刷新还在；
- 调错了不要紧，页面上会浮出「撤销」按钮，点一下即可退回（见下一节）。

**办法二：一键按学号排**

工具条上有「**按学号排序**」按钮，点一下把整份名单按**学号从小到大**重排，序号跟着重排。

- 排序规则：纯数字的按数值大小排（位数不同的，短学号排在前面）；带字母的排在纯数字后面；
- 排完**真的改了数据顺序**，不是只在页面上临时排一下 —— 因为本项目的序号含义就是"同学在完整名单里的位置"，两者必须一致；
- 不适合排序时会拦下来并说明原因：
  - 本班不足 2 人；
  - 有同学正在编辑中（先保存或取消）；
  - 正在搜索筛选（先清空搜索框，否则顺序变了你看不出全貌）；
- **排错了点「撤销」就能退回原来的顺序。**

### 4.10 撤销上一步

删除、移动到别的班、修改信息、调整顺序、按学号排序、批量导入之后，名单卡片上方会浮出一条橙色提示条：

```
上一步：删除「王五」                          [撤销]
```

点「**撤销**」即可把这一步退回去。几点说明：

- **只记最近 20 步**，连续点「撤销」可以一路退回去；
- **只在本页本次打开期间有效** —— 刷新页面、关掉标签页，撤销记录就没了（它不是历史记录功能，只是"手滑保险"）；
- 撤销「移动到别的班」时，**原班和目标班会一起还原**，不会出现半路失踪的同学；
- 没有可撤销的操作时，这条提示条是隐藏的。

### 4.11 导出 CSV（用 Excel 打开）

1. 打开某班的「**班级名单**」页（可以先搜索筛选出你要的那部分）；
2. 点工具条上的「**导出 CSV**」；
3. 浏览器会下载一个文件，形如 `某高校-计算机科学与技术 2026 级 1 班.csv`，**直接双击就能用 Excel / WPS 打开**。

几点说明：

- **导出的是"屏幕上这份"**：搜索了就只导筛选结果，没搜就是全班；
- 文件开头带一个 BOM 标记，所以 **Excel 打开中文不会乱码**（这是纯前端导出最常见的坑）；
- 列顺序与页面一致：**序号 / 姓名 / 性别 / 学号 / 联系方式**，后面再接**本班的自定义字段**（如「宿舍号」）；联系方式写成 11 位手机号时导成 `138-0000-0001` 的格式，没填的栏留空；
- 序号沿用**完整名单**里的位置，和页面上看到的完全一致（所以筛选导出时序号可能是 1、5、9 这样跳着）；
- **导出的文件改完能直接导回来**：表头写的是「姓名 / 性别 / 学号 / 联系方式」（加上自定义字段名），而导入功能正是按这几个字去认列的，认不出来的列会**自动变成本班的字段**，所以「导出 → 在 Excel 里批量改 → 导入」是一个能走通的闭环，加几列也不会丢（见下一节）；
- 需要 Excel 原生的 `.xlsx` 格式时，用 Excel 打开这个 CSV 再「另存为」即可。

### 4.12 批量导入（从 Excel / CSV 一次录一批）

适合"手上有现成的学生名册，不想一条条敲"的场景。

1. 打开某班的「**班级名单**」页 —— **导入是往"当前这个班"里灌**，所以先确认班级没进错；
2. 点工具条上的「**导入**」，页面上展开一个面板；
3. 用下面两种方式**任选一种**给数据：
   - **选文件**：点「选择 CSV 文件」，挑一个 `.csv` 文件（Excel 里点「另存为 → CSV UTF-8」即可导出）；
   - **粘贴**：在 Excel 里选中整块表格按 `Ctrl+C`，粘到页面上的大文本框里 —— **这种方式最省事，不用先存文件**；
     > 选 CSV 文件时，如果中文变成一堆问号，多半是文件存成了 GBK 编码 —— 页面会自动尝试按 GBK 再读一次；仍然不行就改用"粘贴"方式。
4. 点「**识别**」→ 下方出现一张**预览表**：

   | 行 | 姓名 | 性别 | 学号 | 联系方式 | 宿舍号 | 判定 |
   | --- | --- | --- | --- | --- | --- | --- |
   | 2 | 张三 | 男 | 2026110101 | 138-0000-0001 | 3-201 | 新增 |
   | 4 | 李四 | 女 | 2026110101 | 138-0000-0009 | — | 重复 → 跳过 |
   | 5 | 王五 | 男 | 123 | — | — | 跳过：学号格式不对 |

   （「宿舍号」是表格里多出来的一列，会在本班自动建成同名字段。）
   表上方会写明「共识别 N 行 —— 新增 A 位 · 与本班重复 B 位 · 无法导入 C 行」，并说明哪几列会变成新字段。
5. **选冲突处理方式**（只影响"学号与本班重复"的那几行）：
   - **跳过，保留本班原有记录**（默认，最安全）；
   - **覆盖，用表格里的内容替换** —— 会把那几位原有的姓名、性别、联系方式换掉（他们**本来填过、而这次表格里没有的**其它栏会保留不动），所以确认导入前还会再弹窗问一次；
6. 点「**确认导入**」。完成后提示条会告诉你新增几位、覆盖几位、跳过几位、丢掉几行、多出来的列存了几列，以及本班现有多少人。

**关于列怎么对**

- **最省事的方式是带上表头**：第一行只要出现「姓名」「学号」这样的字眼，就会被当成表头，并按表头文字去认每一列 —— 所以就算你把列的顺序调换过，也照样能对上；
- **表里多出来的列不会被丢掉**：只要它没被姓名 / 性别 / 学号 / 联系方式占用、也不是「序号」这类辅助列，就会被当成**本班的新字段**自动建好并写进名单（已经在用的同名字段则直接复用）。所以别人的 Excel 里多几栏（院系、宿舍、备注…）也能一次带进来；
  - 每班最多 8 个自定义字段，超出的列会在提示里说明"因字段已加满没能导入"；
  - 没有表头时列名无从得知，这一条不适用（多出来的列会被忽略）。
- 不带表头也能认，按位置对应：
  - 3 列及以内（或列数更少）→ 姓名 / 学号 / 联系方式；
  - 4 列及以上 → 姓名 / 性别 / 学号 / 联系方式；
  - 如果第一格是纯数字、第二格又不像性别（典型情况：导出的 CSV 把表头那行删掉了，但「序号」那一列还在），会自动往右挪一位。

**几点说明**

- **单元格里带逗号也没关系**：标准 CSV 的引号包裹是支持的（姓名写成 `"张,三"` 能正确解析）；
- **只有姓名和学号是必须的**：缺这两项、学号不符合当前规则、或者**同一个表格里学号重复**，都会被标成"跳过"并写明原因，那一行还会标红；
- **性别和联系方式都不拦人**（0.4.1 起）：留空可以，联系方式填座机、邮箱、QQ 也可以 —— 不再因为"手机号格式不对"把整行丢掉；
- **一批里学号重复以第一条为准**，后面重复的那条跳过；
- **不会删除本班原有的任何同学** —— 无论选"跳过"还是"覆盖"，都只是增和改；
- **整批导入可以一键撤销**：导入前会自动存一份快照，点顶部的「撤销」即可整批退回，不用担心导错（注意：撤销只还原同学名单，导入时自动新建的**字段空列会留下**，不要了可以到「字段」面板删掉）。

### 4.13 删除班级

打开首页，在「班级概览」里找到要删的班级，点卡片右侧的「**删除**」：

1. 弹窗会告诉你**这个班现在有几个人**，并说明名单会一起删掉；
2. 点「确定」删除，点「取消」什么都不动。

几点说明：

- **删除是"连锅端"**：班级和它的整份名单一起消失，所以一定要看仔细；
- **预置班级删了也能找回来**：它们写死在 `app.js` 里，代码删不掉，所以是先记进一份"隐藏名单"藏起来 —— 到首页「数据管理」点「**恢复预置班级**」即可全部恢复；
- **自己新建的班级删了就没了**（它的定义本来也只存在这台电脑上）；
- 恢复预置班级**只影响班级目录**，不会动你已经录入的同学名单。

### 4.14 在另一个标签页改了数据？

不用管，页面会自己跟上。

- 你在另一个标签页新增、删除、修改了同学，**当前名单页会自动重新加载**，并提示「检测到另一个标签页的改动，已自动刷新」；
- 如果你**正在编辑**某一行，页面不会打断你 —— 只提示一句，等你保存或取消之后，点工具条上的「**重新加载**」即可看到最新内容；
- 「重新加载」按钮任何时候都能点，作用就是"重新读一遍本机保存的数据"；如果你有没保存的改动，它会先问你一句；
- **前提是页面通过网址打开**（GitHub Pages，或本地 `http://` 服务）。如果你是**直接双击 HTML 文件**（地址栏是 `file://` 开头），浏览器可能不认为不同标签页属于"同一个站"，自动同步会不生效 —— 这时手动点「重新加载」仍然好使。

### 4.15 修改默认数据（负责人常用）

班级目录和各班名单都集中在 **`app.js` 顶部**，改一处即可。

**（1）学校名 `DEFAULT_SCHOOL`** —— 全站显示的学校名：

```js
var DEFAULT_SCHOOL = '某高校';
```

- 页面上所有「学校名」的位置（顶部标题、页脚、班级全名、网页标签）都取自它；
- **日常改校名不用动代码**：直接打开首页的「**学校设置**」卡片，填上新校名点保存，全站立刻跟着变（存在本机浏览器里）；
- 想让**所有人**打开都看到新校名，才需要改这一行并重新发布。首页「学校设置」里点「恢复默认」即可清掉本机设置、回到这个值。

**（2）班级目录 `DEFAULT_CLASSES`** —— 决定首页能选到哪些班：

```js
var DEFAULT_CLASSES = [
  { id: 'cs-2026-1', school: DEFAULT_SCHOOL, major: '计算机科学与技术', grade: '2026', name: '1 班' },
  { id: 'cs-2026-2', school: DEFAULT_SCHOOL, major: '计算机科学与技术', grade: '2026', name: '2 班' },
  // 加班级：照格式加一行，id 不能和已有的重复
];
```

- `id` 是班级的唯一标识，会出现在网址里（`roster.html?c=cs-2026-1`），只能用英文、数字和短横线；
- `school` 一栏写 `DEFAULT_SCHOOL` 即可，不用重复填校名。

**（3）各班默认名单 `DEFAULT_ROSTERS`** —— 按班级 `id` 分组，**默认是空的 `{}`**：

```js
var DEFAULT_ROSTERS = {
  // 想给某个班预置同学，照下面这样写：
  // 'cs-2026-1': [
  //   { name: '张三',   sid: '2026110101', gender: '男', contact: '13800000001' },
  //   { name: '王雨桐', sid: '2026110102', gender: '女', contact: '13800000002' },
  // ],
};
```

- **默认不预置任何同学**，打开名单页就是一张白纸，由你在页面上录入真实数据 —— 这样别人打开网页时不会看到一串假名字；
- 如果需要"开箱就有一份名单"（比如发给全班之前先把已知信息填好），按注释里的格式往对应班级 id 下面加人即可；
- **改人**：修改对应那一行；**加人**：复制一行粘贴并改内容；**删人**：整行删掉；
- `gender` 一栏写 `'男'` / `'女'`，**也可以整个不写或写成空字符串**（表示"未填写"）；
- `contact` 一栏是**联系方式，选填**：写 11 位手机号时名单页会自动显示成 `138-0000-0001`；写成座机、邮箱也可以（原样显示）；不写或写空字符串都行；
- 想连自定义字段一起预置，照这样写：`extra: { f1: '3-201' }` —— 不过字段得先在页面上的「字段」面板里建好（见 4.19），平时不需要手写这一项；
- 顺序就是名单顺序，**不需要手动写序号，也不需要手动改人数**。

> **一个重要提醒**：如果你之前已经在页面里录入过同学，浏览器里会存有一份本地数据，
> 它的优先级高于默认数组，所以改数组后页面不会立刻变化。
> 这时在浏览器控制台执行 `ClassData.reset('cs-2026-1')`（把参数换成对应班级 id）再刷新，
> 即可清空该班的本地数据、回到你改好的默认名单。

**（4）学号规则 `SID_MIN / SID_MAX / SID_ALLOW_LETTER`** —— 决定"什么算一个合法学号"：

```js
var SID_MIN = 4;            // 最短几位
var SID_MAX = 20;           // 最长几位
var SID_ALLOW_LETTER = false;   // false = 只允许数字；true = 数字和英文字母都可以
```

**这是本项目里最值得先改的一处** —— 因为不同学校的学号规则差别很大：8 位的、10 位的、12 位的，甚至带字母的都有。

改这三个值就够了，**其它地方一个都不用动**：

- **录入页**：输入框的 `pattern`、最大长度、提示文案、示例，全部由它算出来；
- **名单页**：行内编辑保存时的学号校验，用的是同一套规则；
- **批量导入**：判断每一行学号是否合法，也是同一套规则。

几个例子：

| 想要的规则 | 怎么写 |
| --- | --- |
| 4~20 位数字（默认，最宽松） | `SID_MIN = 4; SID_MAX = 20; SID_ALLOW_LETTER = false;` |
| **固定 10 位**数字（不少学校的做法） | `SID_MIN = 10; SID_MAX = 10; SID_ALLOW_LETTER = false;` |
| 8~12 位数字 | `SID_MIN = 8; SID_MAX = 12; SID_ALLOW_LETTER = false;` |
| 4~20 位数字或字母（如 `CS2026`） | `SID_MIN = 4; SID_MAX = 20; SID_ALLOW_LETTER = true;` |

> 改完记得**刷新页面**。用浏览器控制台里 `ClassData.sidHint()` 可以立刻看到当前的规则说明
> （例如 `"固定 10 位数字"`），确认改对了。

### 4.16 换一套配色

打开 `style.css`，改最上面的 `:root` 变量即可。**全站所有颜色都取自这组变量**，改完整个站点会一起变，不会出现"按钮变了但表头还是蓝的"这种情况：

```css
:root {
  --primary: #2f6fed;        /* 主色：链接、按钮、当前页高亮 */
  --primary-dark: #1f56c4;   /* 主色加深：按钮 hover */
  --primary-soft: #eef3ff;   /* 主色浅底：导航 hover、表头背景 */
  --primary-faint: #f8faff;  /* 主色极浅底：表格行 hover */
  --primary-glow: rgba(47, 111, 237, .12);   /* 主色光晕：聚焦光圈、阴影 */
}
```

### 4.17 打印名单 / 导出 PDF

1. 打开某班的「班级名单」页，按 `Ctrl + P`（Mac 为 `Cmd + P`）；
2. 导航栏、页脚、搜索框、按钮、位置提示会**自动隐藏**，表格转为适合黑白打印的线条样式；
3. 在打印对话框里选择打印机，或把目标改成「另存为 PDF」即可导出。

### 4.18 清空本地数据

**最省事的办法**：打开首页，点「**数据管理**」卡片里的「清空本机全部数据」，弹窗确认后即可 ——
它会清掉全部名单、页面上新建的班级、你设置过的校名、各班自己加的字段，以及"删掉过哪些预置班级"这份记录，恢复到出厂状态。

只想把删掉的预置班级找回来、不动其他数据的话，点旁边的「**恢复预置班级**」即可。

也可以在浏览器控制台执行：

- `ClassData.reset('cs-2026-1')` —— 清空**某一个班**的数据，恢复成 `app.js` 里的默认名单（参数换成对应班级 id）；
- `ClassData.restoreHidden()` —— 把删掉的预置班级恢复回来（不会碰名单和校名）；
- `ClassData.resetAll()` —— 清空**全部班级**的数据、页面上新建的所有班级、设置过的学校名、各班的自定义字段，以及预置班级的删除记录，恢复到出厂状态。

执行后刷新页面生效。

### 4.19 给班级加自己的字段（宿舍号、QQ…）

四位基本信息（姓名 / 性别 / 学号 / 联系方式）是固定的。除此之外，**每个班可以再自己加最多 8 栏**，
比如「宿舍号」「QQ」「家长电话」「备注」—— 各班互不影响：1 班加了宿舍号，2 班可以是干净的。

**怎么加**

1. 打开某班的「**班级名单**」页；
2. 点工具条上的「**字段**」，展开面板；
3. 在底部输入框里写一个名字（如「宿舍号」），点「**加一栏**」（或在输入框里按 `Enter`）；
4. 表格里立刻多出一列，录入页也会多出一个同名的输入框。

**怎么改 / 怎么删**

- **改名**：面板里每一行就是一个字段，直接改输入框里的字，改完点一下别处（或按 `Enter`）即生效。
  改名**只换显示的名字，不动内部编号**，所以同学们填过的内容一条都不会丢；
- **删除**：点这一行右侧的「删除」。**注意：全班同学在这一栏里填过的内容会一起清掉，且不能用「撤销」找回**，
  所以会先弹窗确认。只想换名字的话，直接改输入框就行，别删。

**几点说明**

- 加了字段之后：表格多一列、**录入页**多一个输入框、**导出 CSV** 多一列，搜索结果也会一并匹配；
- 每栏的内容最长 60 个字，字段名最长 12 个字（超长会自动截断）；
- **从 Excel 导入时，表里多出来的列会自动变成字段**，不用先来面板里手动建（见 4.12）；
- 字段定义也存在本机浏览器里（存储键 `classInfoSite.fields`），和名单一样不会上传到任何服务器；
- 删除班级时会连这个班的字段定义一起清掉。

### 示例十三：批量修改信息

**输入**：勾选 3 位同学 → 点「批量修改信息」→ 三行同时变成输入框 → 逐行改动，改完点操作条上的「**保存全部**」（或按 `Ctrl + Enter`）。

### 示例十四：调整顺序（以及撤销）

**输入**：在 1 班名单页，把排在第 3 位的「王五」挪到最前面 —— 连点两次他那一行的「上移」；紧接着觉得不合适，点顶部浮出的「撤销」退回。

**输出**：

- 每点一次「上移」，该行就往上挪一位，序号自动重排；
- 页面上方浮出一条橙色提示条：
  ```
  上一步：上移「王五」                          [撤销]
  ```
- 点「撤销」后退回上一步，连点两次就回到原来的顺序；退到头之后提示条自动隐藏。

**几点说明：**

- 排在第 1 位的同学，「上移」按钮是灰的（点不动）；排在最后一位的，「下移」是灰的；
- **搜索筛选状态下不显示这两个按钮** —— 因为调的是完整名单里的位置，先清空搜索再调；
- 撤销记录**刷新页面就清空**，最多记最近 20 步。

### 示例十五：导出 CSV

**输入**：在 1 班名单页的搜索框里输入 `2026` 筛出一部分同学，点工具条上的「导出 CSV」。

**输出**：浏览器下载一个文件 `某高校-计算机科学与技术 2026 级 1 班.csv`，页面提示条（蓝色）：

### 示例十六：删除一个班级，再把它恢复回来

## 6. 数据存放在哪里

| 数据 | 存放位置 | 说明 |
| --- | --- | --- |
| 学校名（默认） | `app.js` 的 `DEFAULT_SCHOOL` | 写在代码里，任何浏览器都能看到 |
| 学校名（已设置） | localStorage `classInfoSite.schoolName` | 首页「学校设置」改过就是这里，只在本机 |
| 班级目录（预置） | `app.js` 的 `DEFAULT_CLASSES` | 写在代码里，任何浏览器都能看到 |
| 班级目录（新建） | localStorage `classInfoSite.classes` | 只在这台电脑这个浏览器里 |
| 预置班级的删除记录 | localStorage `classInfoSite.hiddenClasses` | 删掉预置班级后记在这里；「恢复预置班级」或「清空本机全部数据」会清掉它 |
| 各班同学名单 | localStorage `classInfoSite.students.<班级id>` | **每班一份，互不干扰**；默认为空 |
| 各班自定义字段 | localStorage `classInfoSite.fields` | `{ 班级id: [{ key, label }] }`，也是每班一份；删班级或清空数据会一并清掉 |
| 学号规则 | `app.js` 的 `SID_MIN` / `SID_MAX` / `SID_ALLOW_LETTER` | 写在代码里，录入页 / 名单页 / 批量导入三处共用 |
| 自定义字段上限 | `app.js` 的 `MAX_FIELDS` / `FIELD_LABEL_MAX` / `FIELD_VALUE_MAX` | 字段个数、栏名长度、内容长度的上限 |

名单里每位同学有五个字段：**姓名 `name`、性别 `gender`、学号 `sid`、联系方式 `contact`、附加内容 `extra`**。
`gender` 取 `'男'` / `'女'` / `''`（空字符串表示未填写）；`contact` 是自由文本，选填；
`extra` 形如 `{ 字段key: 值 }`，存这个班自己加的栏（宿舍号、QQ…）的内容 —— 它按**字段 key** 存，
所以把栏名从「宿舍号」改成「寝室」时，同学们已经填好的内容不会丢。

因为按班级分开存，所以 1 班的名单和 2 班的名单是完全独立的两份数据，查重、搜索、序号统计都只在本班范围内进行；
**跨班移动**（把 1 班几位同学转到 2 班）是"从 A 删掉、往 B 加"的一次性动作，不是共享同一份数据。
**批量导入**同理：它只往"当前这个班"里加人 / 改人，不会碰到别的班。

## 已知限制

这几条是实现现状，不是 bug，写清楚避免误会：

1. **数据保存在浏览器本地，不是保存在服务器**。录入的信息存在当前电脑、当前浏览器的 `localStorage` 里，刷新和关机都不会丢，但**换一台电脑、换一个浏览器、或清空浏览器数据就会回到默认名单**。如果需要多人各自提交、汇总到一处，必须接后端接口或改用在线表单工具。
2. **页面上新建的班级同样只存在本机**。想让它成为所有人都能看到的固定班级，需要把信息补进 `app.js` 的 `DEFAULT_CLASSES` 并重新发布。
   - 具体症状：把你本机新建班级的链接（`roster.html?c=c...`）发给别人，对方打开会看到「这个班级编号不存在」——因为他的浏览器里没有这个班。这时页面会就地给出选择器，让他自己选一个班看，不至于卡住。
3. **预置班级的初始名单是空的**，不含任何示例同学 —— 打开就是白纸，录入的真实数据才出现在名单里。只有学校名有个兜底值「某高校」，在首页「学校设置」里改成真实校名即可（不改也能用，只是标题上写着"某高校"）。
4. **导出的格式是 CSV，不是 Excel 原生 `.xlsx`**。用 Excel 打开 CSV 再「另存为」即可转成 xlsx。导入同理：**只能选 CSV 文件、或从 Excel 复制粘贴**，不能直接选一个 `.xlsx` 文件 —— 纯前端解析 xlsx 得引入一个额外的解析库，会破坏"零依赖"这条底线。
   - 另外导入**只增不删**：无论选「跳过」还是「覆盖」，都不会删掉本班原有的同学。要减人请用行内的「删除」或批量删除。
5. **跨标签页同步依赖网址访问**。通过 `http(s)://` 打开时，另一个标签页一改数据本页就自动刷新；但如果你是**直接双击 HTML 文件**（地址栏是 `file://`）打开的，浏览器可能不认为两个标签页属于同一个站，自动同步会失灵 —— 这时点工具条上的「重新加载」手动拉取即可。
6. **删除班级会连整份名单一起删掉**。所以界面上设了两道保险：删除前弹窗告诉你这个班有几个人；预置班级删掉后还能在首页「数据管理」里一键恢复。但要注意 —— **自己新建的班级删掉就找不回来了**；预置班级虽然能恢复，被一起删掉的**名单**也恢复不了。
7. **撤销只是"临时保险"，不是历史记录**。删除、移动、修改、排序、按学号排序、批量导入都能撤销，但只记最近 20 步，且**刷新页面就清空**。跨班移动的撤销会同时还原原班和目标班，不会出现半路失踪的同学。真需要长期可回溯，得接后端数据库。
8. **批量导入的列是按表头或位置对应的，不是"智能识别"**。所以第一行最好写明「姓名 / 性别 / 学号 / 联系方式」；不写表头时按位置猜，猜错了会在预览表里露馅 —— **导之前一定先看一眼预览**。表里多出来的其它列（比如宿舍号）只要第一行写了列名，就会被**自动建成这个班的自定义字段**并把值存下来；没有表头的表则不会凭空生成字段。
9. **性别是选填的，也不参与任何校验**。认不出来的值（比如填「保密」）会被当成"未填写"，而不是报错。这是有意的：性别填错不影响查重和统计，没必要卡住录入。
10. **联系方式完全不校验**。座机、邮箱、QQ 号、微信号都能存，留空也不拦人 —— 这一栏只负责"记下来"，页面不做任何格式判断。确实需要严格收集手机号的话，得自己在导出后处理。
11. **自定义字段每个班最多 8 个，栏名不超过 12 个字，内容不超过 60 个字**。字段是「归属到某一个班」的，换个班就是另一套字段，彼此不共用。**删掉一个字段会连全班同学在这一栏填的内容一起删掉**（删前会弹窗确认，但删完不可撤销）；撤销功能只还原名单内容，不还原字段本身。

## 技术说明

- **技术栈**：原生 HTML5 + CSS3 + ES5 JavaScript（无 ES6 语法，兼容性更好）
- **结构**：
  - `style.css` —— 全站样式，所有颜色收敛在 `:root` 变量里
  - `app.js` —— 数据层，管五件事：
    - **学校名** —— `getSchoolName` / `setSchoolName`
    - **班级目录** —— `listClasses` / `getClass` / `getClassName` / `listMajors` / `listClassesByMajor` / `createClass` / `removeClass` / `restoreHidden`
    - **同学名单**（第一个参数都是班级 id）—— `load` / `save` / `add` / `find` / `update` / `match` / `remove` / `removeMany` / `moveStudents` / `reorder` / `sortBySid` / `reset` / `resetAll`
    - **自定义字段**（同样按班级 id 分开）—— `listFields` / `addField` / `renameField` / `removeField` / `ensureFields` / `normalizeExtra`
    - **学号规则与导入** —— `checkSid` / `sidHint` / `sidExample` / `normalizeGender` / `normalizeContact` / `parseRosterText` / `mergeRoster`
    - 另外提供网址参数工具 `param` / `getClassFromUrl` / `buildUrl`
  - **学号规则集中在 `app.js` 顶部**（`SID_MIN` / `SID_MAX` / `SID_ALLOW_LETTER`）：录入页的输入框校验、名单页行内编辑的校验、批量导入的格式检查，三处都从这一份规则算出来，改一处即可换学校（见 4.15）
  - **自定义字段的上限也在 `app.js` 顶部**（`MAX_FIELDS` / `FIELD_LABEL_MAX` / `FIELD_VALUE_MAX`），想放宽改这三个常量即可
  - **学生记录里的自定义内容存在 `extra`**：形如 `{ 字段key: 值 }`，和字段的显示名解耦 —— 改栏名不会丢内容。`update()` 传 `extraMode:'replace'` 表示整份替换（名单页行内编辑用，能清空某一栏），不传则只并入这次带值的栏（录入页用），完全不传 `extra` 就一个字都不动
  - 三个 HTML 页面 —— 只负责结构与各自的交互逻辑
- **多班级的实现方式**：名单页和录入页不复制多份，而是共用同一份 HTML，靠网址参数 `c` 区分班级。这样新增班级**不需要新建文件**
- **零框架**：未使用 Vue / React / Bootstrap / jQuery 等任何库
- **零依赖**：无 CDN、无外部字体、无构建步骤，拷贝文件夹即可运行
- **代码注释**：所有 HTML / CSS / JS 文件均含中文注释，逐处说明作用，适合作为新手教学参考
