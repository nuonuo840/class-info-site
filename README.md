# 班级信息平台

一个面向**班级负责人**的轻量班级信息平台，用原生 HTML + CSS + JavaScript 写成。
不需要服务器、不需要数据库、不需要联网，用浏览器打开就能用。

平台以**学校**为单位组织，首页按**专业 → 班级**逐级选择，进入后查看该班的同学名单。

**在线体验**：<https://nuonuo840.github.io/class-info-site/>

---

## 1. 项目解决什么问题

一个学院、一个专业往往有多个班级，班级负责人在日常事务里有两件高频小事特别烦：

- **查名单**：要找人、要报人数时，得翻 Excel、翻聊天记录；
- **收信息**：让同学报姓名、学号、手机号，得在群里刷屏统计。

而且这件事要按班级分开做 —— 1 班的名单不能混进 2 班的人，各班数据不能互相干扰。

本项目把这些事做成一个**打开即用的静态网页**：

| 原来的做法 | 现在的做法 |
| --- | --- |
| 每个班一个 Excel，散落各处 | 一个平台装下所有班级，按专业班级进入 |
| 翻 Excel / 群聊记录找学号 | 打开班级名单页，一屏看全，还能搜索 |
| 群里挨个统计姓名学号手机号 | 打开录入页，填完提交，名单页立刻出现 |
| 要装软件、要联网、要登录 | 零安装、零依赖、离线可用 |

**面向的场景很明确**：使用者是班级负责人（非程序员），电脑上不想装任何东西，拷个文件夹就能用。

## 2. 主要功能

### 页面一：首页 `index.html`
- **选择班级**：专业下拉框 + 班级下拉框联动，选好后点「进入班级」直达该班名单，或点「直接录入」去该班录入页
- **班级概览**：每个班级一张卡片，显示班级全名与当前人数，点卡片直接进班
- **新建班级**：预置班级之外，可自己填写「专业 / 年级 / 班级名」创建新班级（保存在本机浏览器）
- 项目介绍与全校统计（共几个班、共多少名同学），人数**自动读取实际数据**，不会对不上

### 页面二：班级名单 `roster.html?c=班级编号`
- **一个页面服务所有班级**：通过网址参数 `c` 指定看哪个班，例如 `roster.html?c=cs-2026-1`
- **失效链接不是死路**：网址没带班级编号（点了旧书签）、或编号不存在（链接被截断、班级被移除）时，页面会**就地给出「专业 → 班级」选择器**，选完点「查看名单」直接进入，不用回首页重来；编号不存在时还会用橙色提示条说明原因
- 页面顶部显示**班级全名**（如「计算机科学与技术 2026 级 1 班」）与**位置提示**（首页 › 专业 › 班级）
- 使用标准 `table / caption / thead / th / tbody / tr / td` 结构展示全班同学
- 五列：**序号、姓名、学号、联系方式、操作**
- **在名单里直接修改同学信息**：点某行右侧的「编辑」，这一行的姓名、学号、手机号就地变成输入框，改完点「保存」即时生效；按 `Enter` 保存、按 `Esc` 取消
- 修改时带完整校验：学号必须 10 位数字、手机号必须 11 位纯数字；**学号改成本班其他人已占用的会被拒绝并给出提示**
- **关键词搜索**：输入姓名、学号或手机号的任意片段即时筛选（输入 `13800000001` 和 `138-0000-0001` 都能搜到）
- 序号取同学在**完整名单**中的位置，搜索结果里序号依然稳定
- 表格下方显示统计：`本班共 N 名同学 · 数据保存在本机浏览器，点右侧「编辑」可修改`
- 窄屏（手机）下表格可横向滚动

### 页面三：信息录入 `form.html?c=班级编号`
- **在页面上直接选班级**：顶部有「专业 → 班级」两个联动下拉框，选哪个班就往哪个班录；选完之后**地址栏会自动更新**，刷新或收藏都不丢
- 网址参数 `c` 只是**默认值**而不是硬性要求：`form.html?c=cs-2026-1` 会默认选中 1 班，之后仍可在下拉框里改成别的班
- **不带参数也能直接打开**：默认选中第一个班级，并用一条蓝色说明条告知你；如果带的是不存在的编号，会给出橙色警告并退回第一个班
- 页面顶部会实时显示「正在录入：某某班」，并同步更新位置提示（首页 › 专业 › 班级）与页面标题
- 三个输入项：**姓名**（必填）、**学号**（必填）、**手机号**（必填）
- 学号格式校验：必须是 **10 位数字**（如 `2026110113`）
- 手机号格式校验：必须是 **11 位数字**（`1` 开头、第 2 位 3~9，如 `13800000013`）；手机上点击输入框会自动弹出数字键盘
- **学号查重**：学号在本班已存在时弹窗确认，选「确定」就用这次填写的信息**覆盖**原记录，选「取消」则原样不动
- 提交后顶部弹出提示条反馈结果（说明录进了哪个班、本班现有多少人），并自动清空三个输入框，方便连续录入下一位同学
  - **班级选择不会被清空** —— 连续给同一个班录入时不用反复重选
- **提交的数据会真正保存下来**（存在浏览器本地），刷新不丢，名单页立刻能看到

### 三个页面通用的功能
- **导航栏**：三个页面互相跳转，且名单页与录入页的链接会**自动带上当前班级**，不会跳到别的班或空页面
- **吸顶导航**：页面滚动时导航栏固定在顶部
- **响应式布局**：电脑、手机都能正常显示
- **打印样式**：打印名单时自动隐藏导航、按钮、搜索框、位置提示，表格转为黑白线条，可直接打印或另存为 PDF
- **无障碍**：表格带 `caption` 与 `scope="col"`，提交结果用 `aria-live` 播报，键盘也能操作
- **零外部依赖**：无框架、无 CDN、无外部字体，断网也完全正常

## 3. 安装方法

**本系统不需要安装。** 没有 `npm install`，没有 `pip install`，也不需要 Node.js 或 Python。

你只需要拿到下面这批文件（**6 个代码文件必须在同一个文件夹里**）：

```
班级信息平台/
├── index.html      首页（选择班级）
├── roster.html     班级名单
├── form.html       信息录入
├── style.css       公共样式（三个页面共用）
├── app.js          数据层（班级目录 + 各班名单，三个页面共用）
├── favicon.svg     浏览器标签页图标
├── README.md       本说明文件
├── CHANGELOG.md    更新日志（各版本改了什么）
└── LICENSE         MIT 开源许可证
```

获取方式三选一：

1. **直接在线用**：打开 <https://nuonuo840.github.io/class-info-site/> ，不下载也能用；
2. **拷到本地**：从 ZIP 解压或拷贝整个文件夹到桌面、U 盘即可；
3. **Git 克隆**：
   ```bash
   git clone https://github.com/nuonuo840/class-info-site.git
   ```

> 注意：`style.css`、`app.js`、`favicon.svg` 都不要和 HTML 文件分开放，否则页面会变成没有样式的白板，或者名单加载不出来。

### 可选：启动本地预览服务

直接双击打开已经完全够用。如果想用 `localhost` 访问，可以在该文件夹下执行：

```bash
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。这一步是**可选的**，跳过不影响使用。

## 4. 使用方法

### 4.1 打开系统

双击 `index.html`，用 Chrome / Edge / Firefox 等现代浏览器打开即可。

### 4.2 选择班级并进入

1. 首页「**选择班级**」卡片里，先在左边的下拉框选**专业**；
2. 右边的下拉框会**联动**列出该专业下的所有班级，选中你要的班；
3. 点「**进入班级**」跳到该班名单页，或点「**直接录入**」去该班录入页。

也可以直接在「**班级概览**」里点某个班的卡片，一步进入。

> 顶部导航栏里的「班级名单」「信息录入」也会跟着你选的班级走，随时点随时进。

### 4.3 新建一个班级

1. 首页下方「**新建班级**」卡片里，填写**专业**、**年级**（默认 2026）、**班级名**（如 `3 班`）；
   - 「专业」输入框会提示已有的专业名，可以直接选，也可以填一个全新的专业；
2. 点「**创建班级**」；
3. 创建成功后，这个班**立刻出现在下拉框和概览卡片里**，并自动选中，可以直接进入。

**几点说明：**

- 新建的班级**只保存在你这台电脑的浏览器里**，不会写进代码文件，也不会同步给别人；
- 同一专业、同一年级下不能创建同名的班级，会提示「这个班级已经存在了」；
- 如果想把它变成"所有人都能看到"的固定班级，需要把它的信息补进 `app.js` 的 `DEFAULT_CLASSES` 数组（见 4.7）。

### 4.4 查看与搜索班级名单

1. 首页选好班级后点「进入班级」，或者在概览里点班级卡片；
2. 页面以表格展示该班全部同学信息，鼠标放在某一行可高亮该行；
3. 在表格上方的搜索框里输入**姓名、学号或手机号**的任意片段，表格会即时筛选；
4. 清空搜索框即恢复完整名单。

### 4.5 录入新同学信息

1. 在首页选好班级后点「直接录入」，或在名单页点「✍️ 给这个班录入新同学」；
2. 页面顶部会显示「正在录入：某某班」，确认班级没选错；
   - **想换班不用回首页**：直接在页面上的「专业 / 班级」下拉框里改，改完全页面（标题、位置提示、导航链接、地址栏）会一起跟着变；
3. 填写「姓名」「学号」「手机号」，三项都是必填；
   - 手机号直接填 11 位数字即可（写成 `138-0000-0001` 也能识别，存进去会统一成纯数字）；
4. 点击「**提 交**」按钮；
5. 提交成功后：
   - 页面顶部出现绿色提示条，显示录入到了哪个班、姓名、学号和本班总人数；
   - 三个输入框自动清空，**班级选择保留**，方便接着录下一位；
   - 切到「班级名单」页，新同学已经在表格里了。

> 也可以直接打开 `form.html`（不带班级参数）：页面不会拦你，会默认选中第一个班级，
> 并用一条蓝色说明条提示这件事，你在下拉框里改一下就行。

**如果学号在本班已经存在**（例如之前漏填了手机号，想补上）：页面会弹出确认框显示该学号原有同学的姓名和手机号，点「确定」就用这次填写的内容覆盖，点「取消」则完全不动。所以**补填手机号的做法是：用同一个学号重新录入一次，确认覆盖即可**。

### 4.6 修改同学信息（在名单页直接改）

1. 打开某班的「**班级名单**」页；
2. 找到要修改的同学，点这一行最右侧的「**编辑**」；
3. 该行的姓名、学号、手机号会就地变成输入框，直接改写内容；
4. 点「**保存**」（或按 `Enter` 键）即生效，页面顶部出现绿色提示条确认；
   - 不想改了：点「**取消**」或按 `Esc` 键，数据完全不动。

**几点说明：**

- **学号也能改**。如果学号当初填错了，改完保存即可。但如果改成**本班其他同学已占用**的学号，会被拒绝并提示，原数据不变。
- **校验不通过时不会清空你的输入**。比如手机号少写一位，页面会提示格式不对并让你接着改，不会把你刚敲进去的内容冲掉。
- **编辑期间搜索框会临时禁用**。这是为了避免筛选刷新把没保存的修改覆盖掉，保存或取消后自动恢复。
- **没保存就关页面会提醒**。处于编辑状态时直接关标签页或跳转，浏览器会弹确认框。
- **修改结果同样存在浏览器本地**，刷新页面依然生效。

### 4.7 修改默认数据（负责人常用）

班级目录和各班名单都集中在 **`app.js` 顶部**，改一处即可。

**（1）班级目录 `DEFAULT_CLASSES`** —— 决定首页能选到哪些班：

```js
var DEFAULT_CLASSES = [
  { id: 'cs-2026-1', school: '某高校', major: '计算机科学与技术', grade: '2026', name: '1 班' },
  { id: 'cs-2026-2', school: '某高校', major: '计算机科学与技术', grade: '2026', name: '2 班' },
  // 加班级：照格式加一行，id 不能和已有的重复
];
```

- `id` 是班级的唯一标识，会出现在网址里（`roster.html?c=cs-2026-1`），只能用英文、数字和短横线；
- 学校名统一由文件开头的 `SCHOOL_NAME` 决定，页面上所有「学校名」的位置都取自它，改一处即可。

**（2）各班默认名单 `DEFAULT_ROSTERS`** —— 按班级 `id` 分组：

```js
var DEFAULT_ROSTERS = {
  'cs-2026-1': [
    { name: '张三',   sid: '2026110101', contact: '13800000001' },
    { name: '王雨桐', sid: '2026110102', contact: '13800000002' },
    // 加人：照格式加一行即可，序号和人数会自动算
  ],
  'cs-2026-2': [
    // 2 班的名单写在这里
  ]
};
```

- **改人**：修改对应那一行；**加人**：复制一行粘贴并改内容；**删人**：整行删掉；
- `contact` 一栏写 11 位数字的手机号即可（不用手动加连字符），名单页会自动显示成 `138-0000-0001`；
- 顺序就是名单顺序，**不需要手动写序号，也不需要手动改人数**。

> **一个重要提醒**：如果你之前已经在页面里录入过同学，浏览器里会存有一份本地数据，
> 它的优先级高于默认数组，所以改数组后页面不会立刻变化。
> 这时在浏览器控制台执行 `ClassData.reset('cs-2026-1')`（把参数换成对应班级 id）再刷新，
> 即可清空该班的本地数据、回到你改好的默认名单。

### 4.8 换一套配色

打开 `style.css`，改最上面的 `:root` 变量即可。**全站所有颜色都取自这组变量**，改完整个站点会一起变，不会出现"按钮变了但表头还是蓝的"这种情况：

```css
:root {
  --primary: #2f6fed;        /* 主色：链接、按钮、当前页高亮 */
  --primary-dark: #1f56c4;   /* 主色加深：按钮 hover */
  --primary-soft: #eef3ff;   /* 主色浅底：导航 hover、表头背景 */
  --primary-faint: #f8faff;  /* 主色极浅底：表格行 hover */
  --primary-glow: rgba(47, 111, 237, .12);   /* 主色光晕：聚焦光圈、阴影 */
}
```

### 4.9 打印名单 / 导出 PDF

1. 打开某班的「班级名单」页，按 `Ctrl + P`（Mac 为 `Cmd + P`）；
2. 导航栏、页脚、搜索框、按钮、位置提示会**自动隐藏**，表格转为适合黑白打印的线条样式；
3. 在打印对话框里选择打印机，或把目标改成「另存为 PDF」即可导出。

### 4.10 清空本地数据

在浏览器控制台执行：

- `ClassData.reset('cs-2026-1')` —— 清空**某一个班**的数据，恢复成 `app.js` 里的默认名单（参数换成对应班级 id）；
- `ClassData.resetAll()` —— 清空**全部班级**的数据，以及页面上新建的所有班级，恢复到出厂状态。

执行后刷新页面生效。

## 5. 输入输出示例

### 示例一：选择班级并进入

**输入**：在首页「专业」下拉框选 `软件工程`，「班级」下拉框自动变为 `2026 级 1 班`，点「进入班级」。

**输出**：浏览器跳转到

```
roster.html?c=se-2026-1
```

页面顶部显示：

```
首页 › 软件工程 › 2026 级 1 班

软件工程 2026 级 1 班
班级名单 · 数据保存在本机浏览器，点表格右侧「编辑」可直接修改
```

### 示例二：新建一个班级

**输入**（在首页「新建班级」里填写）：

| 字段 | 填写内容 |

已创建：数据科学与大数据技术 2026 级 1 班。现在可以直接进入这个班级了。
```

同时「专业」下拉框里多出「数据科学与大数据技术」这一项、「班级概览」里多出一张卡片（显示"共 0 名同学"），并且下拉框**自动选中**了这个新班级。

如果重复创建同一个班，会提示：

```
这个班级已经存在了（数据科学与大数据技术 2026 级 1 班），不用重复创建。
```

### 示例三：正常提交信息

**输入**（在 `form.html?c=cs-2026-1` 中填写）：

| 字段 | 填写内容 |
| --- | --- |

```

```

| --- | --- | --- | --- |

> 手机号在存储时统一为 11 位纯数字（`13800000013`），名单页显示时自动加上连字符变成 `138-0000-0013`；搜索时两种写法都能匹配。

### 示例三·补：在录入页直接改选班级

**输入**：打开 `form.html?c=cs-2026-1`（默认 1 班），在页面上把「专业」改成 `软件工程`，班级下拉自动变为 `2026 级 1 班`，然后填 `林小满 / 2026120199 / 13800001999` 提交。

**输出**：地址栏自动同步成

```
form.html?c=se-2026-1
```

页面顶部的标签、位置提示、导航链接一起变为「软件工程 2026 级 1 班」，提交后提示条显示：

```
已录入到「软件工程 2026 级 1 班」：林小满（学号 2026120199，手机号 13800001999），本班现有 4 名同学。
```

而原来那个 1 班的数据**完全没被碰**——录进了哪个班，由页面上选的那个班决定。

### 示例四：学号格式不符（校验拦截）

**输入**：姓名 `张三`，学号 `123`。

**输出**：表单**不会提交**，浏览器在学号输入框下方弹出原生提示：

```
学号应为 10 位数字
```

（该提示文案来自 `form.html` 中学号输入框的 `title` 属性，由 `pattern="\d{10}"` 规则触发。）

### 示例五：学号重复（弹窗确认是否覆盖）

**输入**：在 1 班，姓名 `李四`、学号 `2026110101`（本班已属于「张三」，手机号 `13800000001`）、手机号 `13900000099`。

**输出**：先弹出确认框：

```
在本班（计算机科学与技术 2026 级 1 班）里，学号 2026110101 已经存在（张三，手机号：13800000001）。

要用这次填写的信息覆盖原来的记录吗？
```

- 点「**确定**」→ 张三这一行被更新为「李四 / 13900000099」，页面顶部显示绿色提示条：
  ```
  已更新：李四（学号 2026110101）的手机号为 13900000099。
  ```
- 点「**取消**」→ 数据完全不动，页面顶部显示红色提示条：
  ```
  已取消，张三的原有信息保持不变。
  ```

> 这个确认框就是**补填手机号**的入口：之前漏填手机号的同学，用同一个学号重填一次、点「确定」即可补上。

### 示例六：手机号格式不符（校验拦截）

**输入**：姓名 `张三`，学号 `2026110113`，手机号 `12345`。

**输出**：表单**不会提交**，浏览器在手机号输入框下方弹出原生提示：

**输入**：在 1 班名单页搜索框里输入 `20261101`。

**输出**：表格只保留学号包含该片段的同学，底部统计文字变为：

```

也可以在搜索框输入手机号片段，如 `138-0000-000` 或 `138000000`，同样能筛出对应同学。

若输入一个不存在的关键词（如 `zzz`），表格会显示：

### 示例八：在名单页修改同学信息

**输入**：在 1 班名单页点第 1 行右侧的「编辑」，把姓名改成 `张三丰`、手机号改成 `13900000009`，然后点「保存」。

**输出**：页面顶部出现绿色提示条：

如果这次把学号改成了本班已存在的 `2026110102`（属于王雨桐），保存会被拒绝，提示条变为红色：

### 示例九：直接打开名单页但没带班级

**输入**：在地址栏直接输入 `roster.html`（不带 `?c=...`，例如从收藏夹里点了一个旧链接）。

**输出**：页面不会把你赶回首页，而是就地摆出选择器：

```
请选择要查看的班级

在下面选好专业和班级，点「查看名单」即可。

  专业 [计算机科学与技术 ▾]   班级 [2026 级 1 班 ▾]

选中后即可查看：计算机科学与技术 2026 级 1 班 · 共 12 名同学

[查看名单]
```

选完点「查看名单」，直接进入该班，网址也变成对应的 `roster.html?c=...`。

> 如果带的是**不存在**的班级编号（如 `roster.html?c=abc`），选择器上方会多出一条橙色警告：
> ```
> 网址里的班级编号「abc」不存在 —— 可能是链接过期了、被截断了，或者这个班是在别的电脑上新建的。
> ```
> 三个真实场景会导致编号失效：**①** 链接在聊天软件里被截断；**②** 班级在 `app.js` 里被改名或移除；
> **③** 把「本机新建班级」的链接分享给别人 —— 新建班级只存在你自己的浏览器里，别人打开必然找不到。

**录入页 `form.html` 的行为略有不同**（更省事）：不带参数时默认选中第一个班级，
并用一条蓝色说明条告诉你，改不改都能直接录。

## 6. 数据存放在哪里

| 数据 | 存放位置 | 说明 |
| --- | --- | --- |
| 班级目录（预置） | `app.js` 的 `DEFAULT_CLASSES` | 写在代码里，任何浏览器都能看到 |
| 班级目录（新建） | localStorage `classInfoSite.classes` | 只在这台电脑这个浏览器里 |
| 各班同学名单 | localStorage `classInfoSite.students.<班级id>` | **每班一份，互不干扰** |

因为按班级分开存，所以 1 班的名单和 2 班的名单是完全独立的两份数据，查重、搜索、序号统计都只在本班范围内进行。

## 已知限制

这几条是实现现状，不是 bug，写清楚避免误会：

1. **数据保存在浏览器本地，不是保存在服务器**。录入的信息存在当前电脑、当前浏览器的 `localStorage` 里，刷新和关机都不会丢，但**换一台电脑、换一个浏览器、或清空浏览器数据就会回到默认名单**。如果需要多人各自提交、汇总到一处，必须接后端接口或改用在线表单工具。
2. **页面上新建的班级同样只存在本机**。想让它成为所有人都能看到的固定班级，需要把信息补进 `app.js` 的 `DEFAULT_CLASSES` 并重新发布。
   - 具体症状：把你本机新建班级的链接（`roster.html?c=c...`）发给别人，对方打开会看到「这个班级编号不存在」——因为他的浏览器里没有这个班。这时页面会就地给出选择器，让他自己选一个班看，不至于卡住。
3. **名单默认数据是示例内容**。`app.js` 里的姓名与联系方式均为占位数据（手机号形如 `1380000000X`），学校名也是泛化的「某高校」，使用前请替换为真实信息。
4. **不支持排序和导出**。名单目前按录入顺序展示，可以搜索但不能按学号排序，也没有导出 CSV/Excel 的功能。
5. **名单页只在打开时读取一次数据**。如果你在另一个标签页新增了同学，刷新名单页即可看到最新数据。
6. **班级不支持删除**。目前只能新建班级，没有提供删除班级或删除同学的入口（这是有意为之：删除是不可逆操作，暂不放进界面）。

## 技术说明

- **技术栈**：原生 HTML5 + CSS3 + ES5 JavaScript（无 ES6 语法，兼容性更好）
- **结构**：
  - `style.css` —— 全站样式，所有颜色收敛在 `:root` 变量里
  - `app.js` —— 数据层，管两件事：**班级目录**（`listClasses` / `getClass` / `getClassName` / `listMajors` / `listClassesByMajor` / `createClass`）和**同学名单**（`load` / `save` / `add` / `find` / `update` / `match` / `reset`，第一个参数都是班级 id），另外提供网址参数工具 `param` / `getClassFromUrl` / `buildUrl`
  - 三个 HTML 页面 —— 只负责结构与各自的交互逻辑
- **多班级的实现方式**：名单页和录入页不复制多份，而是共用同一份 HTML，靠网址参数 `c` 区分班级。这样新增班级**不需要新建文件**
- **零框架**：未使用 Vue / React / Bootstrap / jQuery 等任何库
- **零依赖**：无 CDN、无外部字体、无构建步骤，拷贝文件夹即可运行
- **代码注释**：所有 HTML / CSS / JS 文件均含中文注释，逐处说明作用，适合作为新手教学参考
